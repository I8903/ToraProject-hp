事業内容

TORA PROJECT株式会社は「学び」と「制作」と「営業」を一気通貫で支援し、 個人・中小企業の“成果につながる仕組みづくり”を提供します。

プログラミングスクール事業

未経験から、実務で使えるWeb制作スキルへ。学びを成果に変える伴走型。

Web制作事業

LP・Webサイト・WordPress制作。集客と運用まで見据えた設計を。

営業スクール事業

営業を「感覚」ではなく「再現性」で学ぶ。案件獲得・売上につながる営業力を育成。

私たちの強み

  • “作って終わり”ではなく、成果まで設計

    目的（問い合わせ・予約・採用など）から逆算し、導線・訴求・運用まで含めて整えます。

  • 現場視点で、分かりやすく・実行しやすく

    専門用語を極力使わず、次に何をすれば良いかが明確な形でご提案します。

  • 学び・制作・営業を横断できる体制

    「作れる」だけでなく「届けられる」状態へ。事業の前進に必要な要素をまとめて支援できます。

プログラミングスクール事業

未経験からでも、WebサイトやLPを“自分の手で作れる”状態へ。 さらに、実案件・実務を想定した課題で、仕事につながる力を育てます。

提供内容

  • HTML / CSS / JavaScript の基礎〜実装
  • WordPress構築（テーマ・固定ページ・運用の考え方）
  • Git / GitHub（チーム開発に必要な基礎）
  • Figma（デザイン確認・制作の進め方）
  • マンツーマン面談（学習計画・課題レビュー・次アクション整理）

こんな方におすすめ

  • 未経験からWeb制作スキルを身につけたい
  • 学習が続かないので、伴走してほしい
  • 作れるようになって、仕事につなげたい

Web制作事業

ただ綺麗なだけではなく、目的達成のための「伝え方」を整えるWeb制作。 LP・コーポレート・WordPressまで、運用を見据えて制作します。

対応範囲

  • LP制作（構成設計 / デザイン / コーディング）
  • Webサイト制作（コーポレート / サービスサイト 等）
  • WordPress構築・改修（テーマ調整 / 固定ページ / 投稿設計）
  • 導線改善（CTA設計、フォーム最適化、ページ改善提案）
  • 運用サポート（軽微修正、更新しやすい設計）

制作の考え方

ヒアリングで「誰に、何を、どう届けるか」を整理し、構成・導線・文章の設計を行います。 必要に応じて、改善前提で運用できる形もご提案可能です。

営業スクール事業

営業を「根性論」や「属人的なスキル」で終わらせない。 TORA PROJECTの営業スクールでは、案件獲得・売上につながる営業を、再現できる形で学ぶことを目的としています。

スクールの特徴

  • 営業未経験・苦手意識がある方でも理解できる設計
  • トーク・文章・流れを「型」として体系化
  • 実務・実案件を想定した実践ベースのカリキュラム
  • 感覚ではなく「なぜ刺さるのか」を言語化

学べる内容

  • 営業の基礎設計（ターゲット・提供価値・強みの整理）
  • 営業トーク・提案構成の作り方
  • DM・メール・問い合わせ返信の文章設計
  • 初回商談の進め方・ヒアリングの考え方
  • 断られた理由の分析と改善方法

こんな方におすすめ

  • 営業が苦手で、毎回手探りになっている
  • 案件獲得や受注が安定しない
  • 営業のやり方を体系的に学びたい
  • フリーランス・個人事業主として売上を伸ばしたい

目指すゴール

営業を「やらなきゃいけない作業」ではなく、 自分の価値を正しく伝える手段として使いこなせる状態を目指します。 一時的なテクニックではなく、長く使える営業力を身につけていただきます。

ご依頼の流れ

  1. お問い合わせ：目的・ご状況を簡単にお伺いします。
  2. ヒアリング：課題・目標・スケジュールを整理します。
  3. ご提案・お見積り：実施内容と進め方をご提示します。
  4. 制作/支援開始：進捗共有しながら進めます。
  5. 納品/改善：必要に応じて運用・改善もご相談可能です。

まずはお気軽にご相談ください

「何から相談すればいいか分からない」状態でも大丈夫です。目的と状況を整理するところから一緒に進めましょう！
